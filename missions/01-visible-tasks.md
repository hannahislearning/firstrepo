# Mission Card 01 — Visible Tasks

## Goal
Build a single page (`index.html`) that shows a small list of sample group tasks with their deadlines, so a student can instantly see what is due. No saving, no interaction yet — just the visible list.

## Limits
- Sample data only (fake task names like "Draft intro slide"), hardcoded in the page — no forms, no storage.
- One HTML file plus one CSS file; no frameworks, no server.
- Must be readable and tappable at phone width (~375px).
- No logins, no payments, no external services.

## Self-test (the proof it works)
**Phone-width test:** open `index.html` in your browser, then narrow the window to phone width (or press F12 → toggle device toolbar). You should be able to read every task title and its deadline without scrolling sideways, and each task shows a visible due date.

*Pass = all tasks readable at phone width, no horizontal scrolling, deadlines visible.*
