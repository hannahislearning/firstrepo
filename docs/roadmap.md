# Roadmap — Mission Cards

One Mission Card at a time. Each card = goal + limits + one self-test. Nothing is built until its card is approved.

| # | Mission Card | What exists afterwards |
|---|---|---|
| 01 | **Visible tasks** — a page showing a few sample tasks with deadlines, readable on a phone | Static page, hardcoded sample data |
| 02 | **Add a task** — coordinator action: fill a small form, confirm, task appears | Page + add form, still sample-level |
| 03 | **Mark a task done** — student action: tap, confirm, see status change | Interactive task list |
| 04 | **Remember between visits** — save tasks to localStorage so reopening the page keeps data | Persistence |
| 05 | **Overdue alerts** — deadlines in the past show red "Overdue" | Polished MVP |
| 06 | **Handover** — README explaining how to run and test, matching the learning goals | Ready to demo |

Out of scope for V1 (agreed simplification): logins, coordinator/student role enforcement, shared server database, syncing between devices, payments.
